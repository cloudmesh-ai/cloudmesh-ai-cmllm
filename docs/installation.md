# Installation Guide

This guide describes how to install the Cloudmesh AI CMLLM tool.

## Prerequisites
- Python 3.10 or newer
- Pip (Python package installer)

## Installation

### From Source
```bash
git clone https://github.com/cloudmesh-ai/cloudmesh-ai-cmllm.git
cd cloudmesh-ai-cmllm
pip install -e .
```

## Verifying Installation
Check the version to ensure the tool is installed correctly:
```bash
cmx llm --version
```
